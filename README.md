# 🛒 Grocery and Budget Manager (Frontend)

Smart Household Grocery Budgeting, Live In-Store Cart Tracking & Food Waste Reducer.

A 100% client-side, zero-database web application ready to deploy to **Vercel** with one click.

---

## 🌟 Core Features

- 🛒 **In-Store Shopping Trip Mode**: Live cart HUD with real-time subtotal, budget warnings, item checkboxes `[✓]`, and quantity steppers `[-] [+]`.
- 🧾 **Bill & Receipt Logging**: Log store expenses (DMart, Blinkit, Zepto, Local Kirana) with payment methods and receipt photo uploads.
- 🥫 **Pantry & Fridge Tracker**: Track food freshness (Fresh 🟢, Expiring soon 🟠, Expired 🔴) with 1-click **"Add to Shopping Trip"**.
- 📊 **Household Budget Dashboard**: Monthly target budget, daily spending pace, store breakdowns, and category charts.
- 💾 **Persistent Data**: Automatically saved to `localStorage` in your browser.

---

## 🚀 Deploy to Vercel (1-Click)

1. Push this repository to GitHub.
2. In [Vercel](https://vercel.com/new), click **Import**.
3. Select **Other** as the Framework Preset.
4. Click **Deploy**. Done!
